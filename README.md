# Diez Aesthetics London

Doctor-led medical aesthetics and skin longevity clinic located in King's Cross, Central London. Under the clinical direction of Daniel Diez, the atelier provides facial harmonisation, regenerative polynucleotides, dermal contouring, and advanced medical skin treatments.

## Technology Stack

- **Framework:** Next.js 16 (App Router)
- **UI Library:** React 19
- **Styling:** Tailwind CSS with bespoke stone & slate palette
- **Typography:** Serif (Playfair Display / Cormorant) & Space Grotesk
- **Motion & Transitions:** Framer Motion
- **Icons:** Lucide React & bespoke SVGs

## Project Structure

```
├── content/              # Structured JSON clinical content & treatment data
├── public/
│   ├── assets/images/    # Optimized photography, case studies & brand marks
│   ├── favicon.ico       # Authentic clinic favicon
│   └── icon.png          # App icon
├── src/
│   ├── app/              # Next.js App Router pages, layout, and sitemap
│   ├── components/       # UI components, navigation, modals, and sections
│   ├── lib/              # Content access layer, JSON-LD, and utility helpers
│   └── types/            # TypeScript schemas and validation definitions
└── next.config.mjs       # Next.js configuration
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm run start
```
